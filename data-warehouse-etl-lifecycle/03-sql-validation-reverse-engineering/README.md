# Module 3 — SQL Data Validation & Database Reverse Engineering

📹 **Video walkthrough:** [https://youtu.be/y4coM8ixHpI]

## Summary

Validated and explored the implemented relational database using SQL queries and joins across employee, department, project, task, and technology tables. I also reverse-engineered the database in MySQL Workbench to visualize the implemented schema and verify table relationships and keys.

## What I did

I worked with the implemented database using SQLyog and wrote SQL queries to retrieve and validate information across related tables.

For example, I queried employee/project/task information and used joins to retrieve information such as manager names and email information from related employee and department tables.

I also worked with the database structure in MySQL Workbench, where I reverse-engineered the existing database to generate an ER diagram from the implemented tables.

The reverse-engineered model showed tables including employees, departments, projects, tasks, technologies, and their relationship tables, along with the corresponding primary and foreign keys.
