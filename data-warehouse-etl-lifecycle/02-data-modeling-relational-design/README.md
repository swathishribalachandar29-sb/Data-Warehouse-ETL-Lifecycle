# Module 2 — Data Modeling & Relational Database Design

📹 **Video walkthrough:** [Data Normalization and Data Modelling]

## Summary

Designed and implemented a relational data model for an employee, department, project, task, and technology management system. Developed the conceptual and relational models, defined primary/foreign-key relationships, implemented the schema in MySQL, and validated the resulting database structure using MySQL Workbench.

## What I did

I first created a conceptual data model representing the relationships between entities such as managers, departments, employees, projects, tasks, and technologies.

I defined relationships such as employees working within departments, managers managing employees, projects containing tasks, and tasks being associated with technologies.

I then converted the conceptual design into a more detailed relational model by defining primary keys and foreign keys and identifying relationships between the tables.

After designing the model, I implemented the schema in MySQL using SQL. I created tables such as:

- Manager
- Department
- Employee
- Projects
- Tasks
- TechnologiesUsed
- Task_Tech

I also used MySQL Workbench to visualize the resulting database structure and verify the relationships.
